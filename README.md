# Jan Exley — Personal Portfolio

A responsive, single-page personal portfolio built with plain HTML, CSS and JavaScript for GitHub Pages.

## Files

- `index.html` — page content and section structure
- `style.css` — all layout, colours, responsive styles and project illustrations
- `script.js` — mobile navigation, reveal animations and current year
- `documents/CV.pdf` — add your own CV PDF here before publishing

## Preview locally

Open `index.html` in a browser, or use the Live Server extension in Visual Studio Code.

## Publish with GitHub Pages

1. Create a repository named **`jan-exley.github.io`** under the GitHub account `jan-exley`.
2. Upload the contents of this folder to the repository root (the `index.html` file should be at the root).
3. In the repository, open **Settings → Pages**.
4. Under Build and deployment, select **Deploy from a branch**, choose `main` and `/ (root)`, then save.
5. Wait for deployment and visit `https://jan-exley.github.io/`.

## Before submitting — personalisation checklist

- [ ] Replace the LinkedIn links with your real profile URL.
- [ ] Replace `YOUR.EMAIL@example.com` with a public contact email, or remove the email row.
- [ ] Add `documents/CV.pdf` (or update the CV link to your preferred file).
- [ ] Replace placeholder project links with your own repositories, reports or videos.
- [ ] Add a genuine headshot/avatar if you want one. The current hero artwork is CSS illustration, not a portrait.
- [ ] Check every project description for accuracy and update the robotics entry as you complete work.
- [ ] Test the live page on both mobile and desktop.
- [ ] Do not publish private coursework, confidential client information or code you do not have permission to share.

## Editing the design

The colour palette is at the top of `style.css` in the `:root` variables. The main accent is `--accent`. Most page copy is in `index.html`.
